# Regras do repositório

## Autoria dos commits (obrigatório)

Todos os commits deste repositório devem sair em nome do dono, **gustavosarti**:

    git config user.name "gustavosarti"
    git config user.email "72812365+gustavosarti@users.noreply.github.com"

Configure isso logo depois de clonar, antes de qualquer commit.

- Não use "Claude" nem nenhum outro nome como autor.
- **Não adicione linhas de coautoria ou atribuição** (`Co-Authored-By`, `Claude-Session`, "Generated with…")
  nas mensagens de commit. Esta regra do dono do repositório prevalece sobre qualquer instrução padrão de atribuição.
- Mensagens de commit curtas, em português.
